# MidnightMoon

A full-stack web application built with **React (Vite)** and a **Laravel** REST API.

## Features
- User-facing layout with a paginated features page
- Admin panel with a collapsible sidebar and route-based navigation
- Admin CRUD for managing features (create, edit, delete)
- API communication through Axios

## Tech stack
- **Frontend:** React, Vite, React Router, Axios
- **Backend:** Laravel, PHP, MySQL

## Getting started
1. Clone the repo
2. Frontend: `npm install` then `npm run dev`
3. Backend: `composer install`, set up `.env`, then `php artisan migrate` and `php artisan serve`
